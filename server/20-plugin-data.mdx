---
title: Plugin data on worlds and entities
description: Store a plugin's own data on a world, a chunk, a block entity or an entity as SNBT.
---

Each world object can hold a compound that belongs to plugins, at five levels. All of them take and return SNBT text.

| Call | Holder | Saved in |
|---|---|---|
| `world:plugin_data()`, `world:set_plugin_data(snbt)` | The world | `worlds/<name>/plugin_data.nbt`, with the world |
| `world:chunk_data(cx, cz)`, `world:set_chunk_data(cx, cz, snbt)` | A chunk (loaded chunks only) | The chunk's NBT |
| `world:block_entity_data(pos)`, `world:set_block_entity_data(pos, snbt)` | A block entity | The block entity's NBT |
| `world:entity_data(entity)`, `world:set_entity_data(entity, snbt)` | An entity or its id | The entity's NBT |

```lua
local world = worlds.default()
world:set_plugin_data("{visits:3}")
print(world:plugin_data())
```

Player data is not kept on the world: it lives in the server's player database, so resetting a world never touches it.
