---
title: Introduction
description: The native Basalt Proxy executable and shared network library.
---

Basalt Proxy is written in C++23 and distributed as a native executable.
It uses Wire, the network library shared with
[Basalt Server](../server/introduction.mdx).

The executable provides command-line help, version information and selection of
a configuration directory. See [Installation](installation.mdx) for building
and invoking it.
