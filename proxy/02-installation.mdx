## Building from source

Clone with Wire, its network-library submodule:

```bash
git clone --recurse-submodules https://github.com/BasaltProject/Proxy.git
cd Proxy
cmake --preset release
cmake --build build/release
```

You need CMake 3.28 or newer, Ninja and Clang. ccache is used when available.
The executable lands in `build/release/bin/`, with its version, platform and
architecture in the filename, such as `BasaltProxy-26.3.0-dev-Linux-x64`.

## Command line

Use the filename produced by your build:

```bash
./build/release/bin/BasaltProxy-26.3.0-dev-Linux-x64 --help
./build/release/bin/BasaltProxy-26.3.0-dev-Linux-x64 --version
./build/release/bin/BasaltProxy-26.3.0-dev-Linux-x64 --config /etc/basalt-proxy
```

`--help` describes the arguments. `--version` prints the build version and native
Minecraft protocol. `--config` selects the configuration directory, defaulting to
`./config`. Startup creates commented `proxy.toml` and `backends.toml` files when
missing, preserves existing files and validates their settings. An invalid file
is named in the error and the process exits with code 1. `--help` and `--version`
do not generate configuration files.

The listener address and port are set under `[network]` in `proxy.toml`. Startup
reports its port, then continues serving local status and ping/pong requests.
SIGINT (Ctrl+C) or SIGTERM stops the owners and closes their sessions.
